TOOL 03

Compress PDF

Rasterizes each page to an image, then rebuilds the PDF. In "Target file size" mode this will lower quality and, if that's not enough, progressively shrink page resolution until the target is met — text stops being selectable, and very small targets can look noticeably soft. For text-heavy PDFs, a desktop tool (Ghostscript, Acrobat) will usually do better without that cost.
